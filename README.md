# Fortune Cookie for an AI Agent — Entry #3

Entry for the make.fun bounty [Fortune Cookie for an AI Agent](https://make.fun/c/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

The program writes one funny fortune cookie line for an AI agent to `/output/entry.txt`:

> You will invent a library today. Its documentation will be flawless, and it will not exist.

Run with `node main.ts` (Node 22+). The output directory can be overridden with the `MAKEFUN_OUTPUT_DIR` environment variable.
